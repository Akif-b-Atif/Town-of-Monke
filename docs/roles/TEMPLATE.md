# Role entry template

Copy this block into the matching category page (`town.md`, `mafia.md` or `neutral.md`) and fill it in. Keep the
headings and field names the same so every role reads identically and the "at a glance" table stays easy to update.

```markdown
## Role Name

**Team:** Town | Mafia | Neutral
**Type:** e.g. Town Investigative (`TI`)
**Unique:** Yes | No
**Goal:** one sentence, as shown on the role card
**Attack / Defense:** None | Basic | Powerful | Unstoppable
**Roleblock immune:** Yes | No
**Sheriff result:** Innocent | Suspicious

### What it does
Plain-English description of the ability: when it can be used, what it targets, how many uses.

### What you see
Exactly what the role learns, and when (dawn recap DM, journal, etc.).

### Night order
Where the ability resolves in [How the night resolves](../rules.md#how-the-night-resolves).

### Interactions
- Role X: what happens when they meet
- Jailor: what happens if this role is jailed
- Roleblock / Heal / Alert: how each affects it

### Tips
Two or three practical tips for playing it and for playing against it.
```
