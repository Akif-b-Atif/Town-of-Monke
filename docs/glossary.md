# Glossary

| Term | Meaning |
|---|---|
| **Abstain** | A verdict that counts for neither side. Not pressing a button also abstains |
| **Alert** | The Veteran's ability: shoot all visitors for one night |
| **Alignment / team** | Town, Mafia or Neutral |
| **Archive** | The zip of chats, votes and night results posted in #monke-commands after a game |
| **Attack / defense** | Strength of a kill / resistance to it. See [attack and defense](roles/README.md#attack-and-defense-levels) |
| **Basic / Powerful / Unstoppable** | Attack (and defense) levels 1, 2 and 3 |
| **Death note** | A message from a killer, shown on the victim's body if the kill succeeded |
| **Dawn** | The moment the night resolves, and the report is posted |
| **Defense (phase)** | The 30 seconds in a trial where only the accused speaks |
| **Execute** | The Jailor killing their prisoner (Unstoppable) |
| **Graveyard** | The channel for dead players |
| **Heal** | The Doctor's protection from non-Unstoppable attacks |
| **Journal** | `/journal`: your private results so far |
| **Jail** | The Jailor's overnight prison |
| **Lobby** | The sign-up embed in #monke-lobby |
| **Lynch** | Execution by town vote |
| **Mafia Lair** | The Mafia's night chat channel |
| **Monke Admin** | Discord role that lets someone host games and use admin commands |
| **Noon** | The voting phase |
| **Pardon** | A trial ending without a lynching |
| **Prisoner** | The player jailed for the night |
| **Role card** | The DM that tells you your role |
| **Role list** | The set of roles in a game (public) |
| **Roleblock** | An Escort cancelling someone's night action |
| **Slot** | Your public player number (1 to 20) |
| **Stalemate** | Three full cycles with no deaths, ending the game in a draw |
| **Token** | A shorthand in role lists such as `TI` or `RT`. See [roles](roles/README.md#role-types-and-the-tokens-you-use-in-role-lists) |
| **Unique** | A role that can only appear once per game |
| **Verdict** | The Guilty / Innocent / Abstain vote after a defense |
| **Visit** | A night action that targets someone (investigate, heal, roleblock, kill) |
| **Will** | A message posted when you die |
