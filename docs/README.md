# Town of Monke documentation

Town of Monke is a Discord bot that runs a *Town of Salem*-style game of hidden roles, night actions, trials and lynches,
entirely inside Discord. Pick your path:

## I want to play

1. **[Player guide](player-guide.md)**: joining, the channels, your first game, what the buttons do
2. **[Roles](roles/README.md)**: every role, what it does, and how it interacts
3. **[Game rules](rules.md)**: the complete rules, including the exact order a night resolves
4. **[Glossary](glossary.md)**: the vocabulary
5. **[Command reference](commands.md)**: slash commands for players

## I want to host games in my server

1. **[Admin guide](admin-guide.md)**: setup, hosting a game, moderation, cleanup
2. **[Role lists and settings](role-lists-and-settings.md)**: choosing roles, phase lengths and presets
3. **[Command reference](commands.md)**: all admin commands
4. **[Troubleshooting](troubleshooting.md)**: when something goes wrong

## I run the bot

1. **[Hosting the bot](hosting.md)**: install, Discord application, invite, configuration, backups, updating
2. **[Troubleshooting](troubleshooting.md#running-the-bot)**

## I want to contribute

1. **[Development guide](development.md)**: architecture, testing, and the checklist for adding a role

## Version

These docs describe **Town of Monke 1.1.0**: 10 roles, one per role type. **Version 2.0** will add many more roles. The role
docs are already organised by category (with a [template](roles/TEMPLATE.md)) so new roles are added as entries rather than
as new structure.
